# 📚 Mini Guia de Estudos com NotebookLM

## 📌 Sobre o projeto

Este projeto tem como objetivo apresentar uma experiência de uso da Inteligência Artificial como ferramenta de apoio aos estudos, utilizando o NotebookLM para organizar informações, revisar conteúdos e facilitar o aprendizado.

A proposta foi criar um caderno temático com materiais selecionados e utilizar recursos de IA para explorar diferentes formas de estudar, como criação de resumos, perguntas, explicações e organização do conhecimento.

O projeto faz parte de uma atividade prática envolvendo o uso consciente da Inteligência Artificial no processo de aprendizagem.

---

# 🎯 Objetivos

Os principais objetivos deste projeto foram:

- Explorar o uso do NotebookLM como ferramenta de estudo;
- Entender como a Inteligência Artificial pode auxiliar na organização de conteúdos;
- Criar uma forma mais prática de revisar materiais;
- Desenvolver habilidades de pesquisa, organização e curadoria de informações;
- Aplicar conceitos de IA em uma situação real de aprendizado.

---

# 🤖 O que é o NotebookLM?

O NotebookLM é uma ferramenta de Inteligência Artificial criada para auxiliar na análise e organização de informações.

Diferente de um chatbot comum, ele permite adicionar fontes próprias, como documentos, textos e arquivos, utilizando esse conteúdo como base para responder perguntas e gerar novos materiais de estudo.

Algumas possibilidades de uso:

- Criar resumos automáticos;
- Fazer perguntas sobre os materiais adicionados;
- Gerar explicações de assuntos complexos;
- Auxiliar na revisão para provas e estudos;
- Organizar ideias principais de um conteúdo.
