# 📖 Sobre o Projeto

O NotebookLM é uma ferramenta de Inteligência Artificial desenvolvida para auxiliar no processo de aprendizagem a partir de documentos fornecidos pelo próprio usuário.

Neste projeto, utilizei o NotebookLM para estudar **Banco de Dados Relacional e SQL**, explorando diferentes técnicas de Engenharia de Prompts para produzir respostas mais claras, organizadas e fundamentadas nas fontes selecionadas.

Além da utilização da ferramenta, toda a experiência foi documentada neste repositório para demonstrar o processo de estudo, os resultados obtidos e as lições aprendidas.

---

# 🎯 Objetivos

Este projeto teve como principais objetivos:

- Explorar o NotebookLM como ferramenta de apoio aos estudos;
- Aprender conceitos fundamentais de Banco de Dados Relacional;
- Revisar os principais comandos SQL;
- Experimentar diferentes estratégias de Engenharia de Prompts;
- Produzir um material de revisão reutilizável para estudos futuros;
- Documentar toda a experiência em um repositório GitHub.

# ⚠️ Dificuldades Encontradas

Durante o desenvolvimento foi possível observar alguns pontos importantes:

- Prompts muito genéricos tendem a gerar respostas extensas;
- Prompts específicos produzem respostas mais objetivas;
- A qualidade das respostas depende diretamente da qualidade das fontes utilizadas;
- O NotebookLM limita suas respostas ao conteúdo fornecido, reduzindo o risco de informações incorretas.

Essas observações reforçam a importância da Engenharia de Prompts na obtenção de resultados mais úteis.

# 📚 Miniguia de Estudos

## O que é um Banco de Dados Relacional?

É um sistema responsável por armazenar informações em tabelas relacionadas entre si por meio de chaves.

---

## Conceitos Fundamentais

### Banco de Dados

Conjunto organizado de informações.

### Tabela

Estrutura onde os dados são armazenados.

### Registro

Cada linha presente em uma tabela.

### Campo

Cada coluna de uma tabela.

### Chave Primária (Primary Key)

Identifica unicamente cada registro.

### Chave Estrangeira (Foreign Key)

Relaciona diferentes tabelas.

### SQL

Linguagem utilizada para criar, consultar e manipular bancos de dados relacionais.

---

```sql

CREATE TABLE

```

# 🎓 Aprendizados

Ao longo deste projeto foi possível compreender que o NotebookLM pode ser utilizado como uma ferramenta eficiente para aprendizagem ativa.

Os principais benefícios observados foram:

- Organização dos conteúdos;
- Produção automática de resumos;
- Criação de glossários;
- Geração de perguntas para revisão;
- Respostas fundamentadas em fontes confiáveis;
- Apoio ao estudo de conteúdos técnicos.

Além disso, ficou evidente a importância da Engenharia de Prompts para direcionar a IA e obter respostas mais precisas.

---

# 📌 Conclusão

O NotebookLM demonstrou ser uma ferramenta extremamente útil para estudantes e profissionais que desejam organizar materiais de estudo, revisar conteúdos e aprofundar conhecimentos utilizando Inteligência Artificial.

A experiência também reforçou que a qualidade das respostas depende da escolha de boas fontes e da elaboração de prompts claros e objetivos.

Este projeto permitiu consolidar conhecimentos sobre Banco de Dados Relacional e SQL, ao mesmo tempo em que desenvolveu habilidades relacionadas ao uso prático de IA aplicada à aprendizagem.
